An entry for the make.fun bounty [The Printer Finally Answers](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907): one line, written as the office printer's comeback to everyone staring at it after one jam too many.

## The line

> My tray holds 250 sheets. You loaded 251 at 4:47 PM. I counted them twice. One of them is now inside me.

## How it works

`main.py` (Python 3.13, standard library only) writes that single line to `/output/entry.txt`. It checks the line is 1–240 characters, a single line, and free of em dashes before writing.

Run it with:

```sh
python3 main.py
```
